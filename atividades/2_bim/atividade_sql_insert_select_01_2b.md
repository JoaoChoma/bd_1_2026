# Atividade — SQL com PostgreSQL/Supabase - 01 - 02 b

# Cenário

Uma loja precisa controlar suas **categorias** e **produtos**.

```text
CATEGORIA(
    id_categoria PK,
    nome
)

PRODUTO(
    id_produto PK,
    nome,
    preco,
    estoque,
    id_categoria FK → CATEGORIA.id_categoria
)
```

---

## Exercício 1 — Criando CATEGORIA

Crie a tabela `categoria`.

Requisitos:

- `id_categoria`: `BIGINT`, chave primária e gerado automaticamente;
- `nome`: `VARCHAR(100)` e obrigatório.

No PostgreSQL/Supabase, utilize:

```sql
BIGINT GENERATED BY DEFAULT AS IDENTITY
```

Ponto de partida:

```sql
CREATE TABLE categoria (
    ...
);
```

---

Identifique:

1. quais colunas foram criadas;
2. qual é a chave primária;
3. qual coluna possui `NOT NULL`;
4. qual coluna possui geração automática.

## Exercício 3 — Criando PRODUTO

Crie a tabela `produto`:

| Coluna | Definição |
|---|---|
| `id_produto` | `BIGINT`, PK e gerado automaticamente |
| `nome` | `VARCHAR(100)` e obrigatório |
| `preco` | `NUMERIC(10,2)` e obrigatório |
| `estoque` | `INTEGER`, obrigatório e `DEFAULT 0` |
| `id_categoria` | `BIGINT`, obrigatório e FK |

Regras:

```text
preco >= 0
estoque >= 0
```

Relacionamento:

```text
PRODUTO.id_categoria
        ↓
CATEGORIA.id_categoria
```

Utilize:

```sql
PRIMARY KEY
FOREIGN KEY
REFERENCES
NOT NULL
CHECK
DEFAULT
```

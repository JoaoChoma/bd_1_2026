# Lista de Exercícios — Manipulação de Dados com SQL

## 1. Objetivo

Praticar progressivamente os comandos SQL para inserir, consultar, atualizar e excluir registros em um banco de dados relacional.

---

## 2. Preparação do ambiente

Utilize o **SQL Editor do Supabase**. Considere o modelo lógico:

```text
CATEGORIA(id_categoria PK, nome)
PRODUTO(id_produto PK, nome, preco, estoque, id_categoria FK → CATEGORIA.id_categoria)
```

### Script de criação das tabelas

```sql
CREATE TABLE categoria (
    id_categoria BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(100) NOT NULL UNIQUE
);

CREATE TABLE produto (
    id_produto BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    preco NUMERIC(10,2) NOT NULL CHECK (preco >= 0),
    estoque INTEGER NOT NULL DEFAULT 0 CHECK (estoque >= 0),
    id_categoria BIGINT NOT NULL,
    CONSTRAINT fk_produto_categoria
        FOREIGN KEY (id_categoria)
        REFERENCES categoria(id_categoria)
);
```

> Utilize um projeto ou esquema de testes: a atividade inclui atualizações e exclusões.

# Parte 1 — Inserção de dados

## Exercício 1 — Inserção simples

Cadastre as categorias **Informática**, **Escritório**, **Eletrônicos**, **Acessórios** e **Games**.

- Utilize um `INSERT INTO` para cada categoria.
- Não informe `id_categoria`.
- Observe a geração automática dos identificadores.

## Exercício 2 — Inserção múltipla

Cadastre todos os produtos abaixo utilizando **um único `INSERT INTO`**:

| Produto | Preço (R$) | Estoque | Categoria |
|---|---:|---:|---|
| Notebook | 3500,00 | 5 | Informática |
| Mouse | 80,00 | 20 | Informática |
| Teclado | 150,00 | 15 | Informática |
| Monitor | 1200,00 | 8 | Eletrônicos |
| Impressora | 900,00 | 4 | Escritório |
| Caderno | 25,00 | 50 | Escritório |
| Headset | 250,00 | 12 | Acessórios |
| Controle | 300,00 | 10 | Games |

- Não informe `id_produto`.
- Utilize os identificadores corretos das categorias, consultando-os previamente; não presuma que começam em 1.
- Na instrução SQL, escreva os números decimais com **ponto**, por exemplo `3500.00`.

## Exercício 3 — Valores padrão

Cadastre **Webcam**, preço R$ 180,00, categoria Informática, e **Cabo HDMI**, preço R$ 35,00, categoria Acessórios, **sem informar `estoque`**.

Depois, consulte os produtos. Qual valor foi atribuído ao estoque? Por quê?

# Parte 2 — Consultas simples com SELECT

## Exercício 4 — Consultando registros

Escreva consultas que apresentem:

**a)** Todos os registros de `produto`.  

**b)** Todos os registros de `categoria`.  

**c)** Somente nome e preço dos produtos.  

**d)** Somente nome e estoque dos produtos.

## Exercício 5 — Renomeando colunas

Utilize `AS` para apresentar as colunas de `produto` com estes nomes no resultado:

| Coluna original | Nome exibido |
|---|---|
| `nome` | `produto` |
| `preco` | `valor_unitario` |
| `estoque` | `quantidade_disponivel` |

## Exercício 6 — Ordenando registros

Utilize `ORDER BY` para:

**a)** Produtos em ordem alfabética.  

**b)** Produtos do maior para o menor preço.  

**c)** Produtos do menor para o maior estoque. 

**d)** Produtos em ordem decrescente de identificador.

**Responda:** qual a diferença entre `ASC` e `DESC`?

## Exercício 7 — Limitando resultados

Utilize `ORDER BY` e `LIMIT` para:

**a)** Mostrar os cinco primeiros produtos em ordem alfabética.  

**b)** Mostrar os três produtos mais caros.  

**c)** Mostrar os quatro produtos com menor estoque.

# Parte 3 — Consultas condicionais com WHERE

## Exercício 8 — Condições numéricas

Consulte:

**a)** Produtos com preço superior a R$ 500,00. 

**b)** Produtos com preço inferior a R$ 100,00.

**c)** Produtos com estoque igual a 10.  

**d)** Produtos com estoque maior ou igual a 15. 

**e)** Produtos com preço diferente de R$ 150,00.

## Exercício 9 — Combinando condições

Utilize `AND` e `OR` para consultar:

**a)** Preço superior a R$ 100,00 e estoque superior a 10.  

**b)** Preço inferior a R$ 50,00 ou superior a R$ 1.000,00. 

**c)** Estoque entre 5 e 15 unidades, incluindo limites.  

**d)** Preço superior a R$ 200,00 **e** estoque inferior a 10.

## Exercício 10 — Buscando textos

Utilize `LIKE` ou `ILIKE` para:

**a)** Produtos cujo nome começa com `M`.  
**b)** Produtos cujo nome termina com `o`.  
**c)** Produtos cujo nome contém `book`.  
**d)** Produtos cujo nome contém `a`, independentemente de maiúsculas e minúsculas.

**Responda:** qual a diferença entre `LIKE` e `ILIKE` no PostgreSQL?

# Parte 4 — Atualização de registros

## Exercício 11 — UPDATE simples

Atualize:

**a)** Preço de `Mouse` para R$ 95,00.  
**b)** Estoque de `Notebook` para 8 unidades.  
**c)** Preço de `Teclado` para R$ 175,00.  
**d)** Nome de `Controle` para `Controle sem fio`.

Use `WHERE` e verifique cada alteração com `SELECT`.

## Exercício 12 — Atualizando vários atributos

O produto `Monitor` passa a ter preço **R$ 1.350,00** e estoque **12**.

Realize as duas alterações em **um único `UPDATE`**.

## Exercício 13 — Atualização com cálculo

Aumente em **10%** o preço dos produtos da categoria **Informática**, preservando os demais.

Dica:

```sql
preco = preco * 1.10
```

Antes do `UPDATE`, consulte os produtos que serão afetados.

## Exercício 14 — Atualização condicional

Acrescente **cinco unidades** ao estoque de todos os produtos que possuem **menos de dez unidades**.

O estoque deve ser **incrementado**, não substituído pelo valor 5. Consulte os resultados.

# Parte 5 — Exclusão de registros

## Exercício 15 — DELETE simples

**a)** Exclua o produto `Webcam`.  
**b)** Exclua o produto `Cabo HDMI`.  
**c)** Consulte os produtos para verificar as exclusões.

**Responda:** o que aconteceria ao executar `DELETE FROM produto;` sem `WHERE`?

## Exercício 16 — Exclusão condicional

1. Cadastre dois novos produtos com estoque igual a zero.
2. Utilize `SELECT` para identificar quais registros serão excluídos.
3. Exclua os produtos cujo estoque seja igual a zero.
4. Consulte a tabela novamente.

## Exercício 17 — Integridade referencial

Tente excluir a categoria **Informática**, que ainda possui produtos associados.

**a)** O PostgreSQL permitiu a exclusão?  
**b)** Qual restrição foi envolvida?  
**c)** Por que a operação foi impedida, se esse foi o caso?  
**d)** Como seria possível excluir a categoria sem violar a integridade referencial?

Não remova nem altere a chave estrangeira.

# Parte 6 — Desafios integrados

## Exercício 18 — Gerenciamento de estoque

A loja realizou as seguintes operações:

1. Recebeu **10 unidades adicionais** de `Notebook`.
2. Vendeu **3 unidades** de `Mouse`.
3. Aumentou o preço de `Impressora` em **5%**.
4. Removeu `Caderno` do catálogo.
5. Deseja consultar produtos com estoque inferior a **10 unidades**.

Escreva os comandos necessários usando `UPDATE`, `DELETE` e `SELECT` com `WHERE`.

Não use valores fixos quando a operação exigir incrementar ou reduzir um valor existente. Considere o estado do banco após os exercícios anteriores.

## Exercício 19 — Campanha promocional

Escreva **uma única consulta** para apresentar produtos que atendam a todos os critérios:

- Preço entre R$ 100,00 e R$ 1.000,00, incluindo os limites.
- Estoque superior a cinco unidades.
- Ordem do maior para o menor preço.
- Exibir somente os cinco primeiros resultados.
- Apresentar apenas as colunas `nome`, `preco` e `estoque`.
